# Brightdesk Pages contributor instructions

## Runtime
Use exactly Node.js **24.22.2 LTS**. Do not change the pinned runtime in package.json, .nvmrc, .node-version, .npmrc, the dev container or GitHub Actions without explicit project-owner approval.

## Product identity
The product in this repository is **Brightdesk Pages**. Use that exact name in customer-facing text, release titles and installer descriptions. Describe distribution only in terms of desktop installers.

Brightdesk is an independent product. Use original names, source code, interface design and artwork. Do not claim Microsoft affiliation or copy proprietary Microsoft code or assets.

## Related Brightdesk products
The wider Brightdesk Office Suite contains exactly these approved products: Pages, Sheets, Decks, Notes, Database, Forms, Lists, Planner, To Do and Workspace.

Do not add Outlook, OneDrive, Teams or any other unapproved product.

## Distribution
Prepare desktop installers for Windows, macOS and Linux. Keep installer names and release titles centred on Brightdesk Pages. Do not publish a GitHub Release unless the project owner explicitly selects the publish option.

## Release safety
Do not claim an installer is ready until its platform build, legal files, checksum verification and release tests have passed.
