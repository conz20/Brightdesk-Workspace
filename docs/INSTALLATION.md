# Installing Brightdesk Workspace

## Do I need Node.js?

**No. You do not need to download or install Node.js to use Brightdesk Workspace.**

The Brightdesk Workspace desktop installer includes the runtime it needs. Install Brightdesk Workspace using the package for your computer, then open it normally.

Node.js 24.22.2 is used by the Brightdesk development team and automated build systems to prepare and test packages. It is not a separate customer installation requirement.

## Choose the package for your computer

Use only the package built for your operating system:

- **Windows:** Brightdesk Workspace Windows x64 installer (.exe)
- **macOS:** Brightdesk Workspace universal disk image (.dmg), package installer (.pkg) or archive (.zip)
- **Linux:** Brightdesk Workspace x64 AppImage or Debian package (.deb)

Download the package from the official Brightdesk Workspace release page when that release is published. Open it and follow the installation steps shown by your operating system. A package that is not listed on the official release page has not been published.

## Terms and Conditions

The Brightdesk Terms and Conditions apply to Brightdesk Workspace. Depending on the package format, the agreement is presented by the installer or in a blocking agreement screen on first launch.

Read the agreement and choose **Accept** to continue. Choose **Decline**, or close a blocking first-launch agreement, to cancel. The product workspace must remain unavailable until the current Terms have been accepted. Changed Terms require fresh acceptance.

## Removing Brightdesk Workspace

Use your operating system's normal removal route:

- **Windows:** Open **Settings → Apps → Installed apps**, find **Brightdesk Workspace**, and choose **Uninstall**. You can also use the Brightdesk Workspace uninstall entry in the Start menu.
- **macOS:** Quit Brightdesk Workspace. In Finder, open **Applications** and move **Brightdesk Workspace** to the Trash. This removes the application bundle.
- **Linux DEB:** Use your desktop's software manager or package manager to remove **Brightdesk Workspace**.
- **Linux AppImage:** Quit Brightdesk Workspace, then delete the AppImage file.

Normal removal must preserve your documents, projects and other user-profile data. It must not silently delete your files or application data. Back up important files before removing software, and do not delete Brightdesk data folders as part of an ordinary uninstall.

## Important

- Do not install Node.js just to use Brightdesk Workspace.
- Do not run Brightdesk Workspace from Terminal or Command Prompt.
- Use the package intended for your operating system and architecture.
- Only use release files that have passed the Brightdesk verification checks.

These instructions describe the configured package formats and expected native removal routes. Successful installation, first launch, upgrade, uninstallation and data-preservation behaviour still need to pass real native checks on Windows, macOS and Linux before release.
