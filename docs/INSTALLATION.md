# Installing Brightdesk Pages

## Do I need Node.js?

**No. You do not need to download or install Node.js to use Brightdesk Pages.**

The Brightdesk Pages desktop installer includes the runtime it needs. Install Brightdesk Pages using the installer for your computer, then open it normally.

Node.js 24.22.2 is used by the Brightdesk development and automated build systems to prepare and test the installers. It is not a separate customer installation requirement.

## Choose the installer for your computer

Use only the installer built for your operating system:

- **Windows:** Brightdesk Pages Windows installer (.exe)
- **Mac:** Brightdesk Pages macOS installer (.dmg or .pkg)
- **Linux:** Brightdesk Pages portable package or Debian package (.deb)

Download the installer from the official Brightdesk Pages release page. Open it and follow the installation steps shown by your operating system.

## Important

- Do not install Node.js just to run Brightdesk Pages.
- Do not open Brightdesk Pages by running a command in Terminal or Command Prompt.
- Install Brightdesk Pages like a normal desktop program.
- Only use release files that have passed the Brightdesk release verification checks.

If an installer for your operating system is not listed on the official release page yet, that installer has not been published.
