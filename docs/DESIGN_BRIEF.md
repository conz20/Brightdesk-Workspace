# Brightdesk Workspace — product design brief

## Purpose
A local-first home for bringing project pages, notes, checklists and resources together.

## Core experience
- Create workspaces and project pages.
- Add and arrange content blocks.
- Bring notes, tasks and resource links into one view.
- Keep context visible with clear navigation and recent activity.
- Store user work locally and make export/recovery predictable.

## Visual direction
Use the shared Brightdesk shell with an indigo Workspace accent. Design a calm project home with flexible content cards, readable page hierarchy and simple block controls. Make it obvious how to add a page, checklist, note or resource without turning the workspace into an overcrowded dashboard.

## Status
**Scaffold only.** This repository currently contains visual assets and a design brief; it does not yet contain runnable application source, a package manifest or a desktop build. The README preview is a design target, not an implemented screen.
